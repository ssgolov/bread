# Кнопка «⏱ Таймеры» — как настроить один раз

Приложение открывает ссылку вида:

```
shortcuts://run-shortcut?name=Хлеб%20таймеры&input=text&text=205,235,265,295
```

`text` — **минуты от текущего момента** до каждого оставшегося складывания
(в примере: через 205, 235, 265 и 295 минут). Время, а не даты — чтобы Команде
не пришлось ничего парсить.

Команду с именем **«Хлеб таймеры»** надо один раз собрать в приложении «Команды».
Дальше она работает как кнопка.

---

## Сборка

1. «Команды» → **＋** → «Новая команда».
2. Название: **Хлеб таймеры** (ровно так, важен каждый символ).
3. В настройках команды (ⓘ) включите **«Показывать в Share Sheet»** — не обязательно,
   но удобно для ручных проверок.
4. Добавьте действие **«Разделить текст»** (Split Text):
   - Вход: **Вход команды** (Shortcut Input)
   - Разделитель: **Свой** → `,`
5. Добавьте **«Повторить с каждым»** (Repeat with Each) и внутрь положите
   действие таймера (см. проверку ниже).

---

## Сначала проверьте: есть ли действие таймера

Это единственное место, где я не могу гарантировать детали — набор действий
в iOS 26 мог измениться. Откройте поиск действий и введите **«таймер»**.

**Если действие есть** (обычно «Запустить таймер» / Start Timer):
внутри «Повторить с каждым» поставьте его, длительность — **Повторяемый элемент**,
единицы — **минуты**. Всё, команда готова.

**Если действия нет**: есть два обходных пути, оба рабочие.

- *Путь А — будильники.* Действие «Переключить будильник» в Shortcuts есть точно.
  Логика та же, только вместо таймера создаётся будильник на абсолютное время:
  нужно прибавить «Повторяемый элемент» минут к «Текущей дате» и передать результат.
- *Путь Б — уведомление.* Действие «Показать уведомление» с текстом
  «Складывание, минут: <элемент>». Не звонит, но всплывает на экране.

Мой совет: сначала попробуйте основной путь. Если таймеры создаются — на этом всё.

---

## Проверка

1. Откройте приложение, нажмите **Старт** (или просто откройте, если план уже идёт).
2. Нажмите **⏱ Таймеры**.
3. Должен произойти переход в «Команды» и всплыть сообщение о запуске.
4. Откройте «Часы» → вкладка «Таймеры»: там должно быть столько таймеров,
   сколько складываний ещё впереди.
5. Для проверки поставьте старт «Сейчас» и нажмите кнопку — должно появиться 4 таймера
   с интервалом 30 минут.

Если таймеры не появились — почти наверняка имя команды не совпало
(«Хлеб таймеры» против «Хлеб-таймеры»). Проверьте посимвольно.

---

## Что важно понимать

- **Таймеры не переживают перезагрузку iPhone.** Будильники — переживают.
  Поэтому утренняя выпечка ставится будильником, а не таймером.
- **Обратной связи нет**: приложение не узнает, создались ли таймеры, и не может
  их отменить. «+15 минут» — это не правка, а новый таймер; старый убирается руками.
- Кнопка отправляет **только оставшиеся** складывания. Если первое уже прошло,
  таймеров будет три, а не четыре.
- Если нажать кнопку меньше чем за 30 секунд до складывания, этот шаг пропускается —
  иначе получился бы таймер на 0 минут.
