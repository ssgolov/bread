# Хлеб — планировщик выпечки (PWA)

Ставится на iPhone как обычное приложение, работает офлайн, прогресс переживает
закрытие и перезагрузку телефона.

## Формула из заметок

Всё считается от одного якоря — момента, когда поставлена закваска (`T0`).

| Смещение | Шаг |
|---|---|
| `T0` | Поставить закваску |
| `T0 + 2:00` | Аутолиз (мука + вода), за час до готовности закваски |
| `T0 + 3:00` | Закваска готова → замес с солью |
| `T0 + 3:30` | Складывание 1 (отдых 30 мин) |
| `T0 + 4:00` | Складывание 1 (отдых 60 мин) |
| `+30 мин × 4` | Складывания 2, 3, 4 |
| `T0 + 5:30…6:00` | Формовка → холодильник |
| `T0 + 18:00` | В печь, окно 2 часа |

Выпечка привязана не к складываниям, а к старту — ровно **+18 часов**.
Обе записи это подтверждают: 14:00 → 08:00, 16:00 → 10:00.

## Файлы

```
index.html            приложение целиком (HTML + CSS + JS, без зависимостей)
manifest.webmanifest  имя, иконки, режим standalone
sw.js                 service worker — офлайн-кэш
icon-192.png          иконка
icon-512.png          иконка
apple-touch-icon.png  иконка для iOS

build.sh              подъём версии кэша в sw.js
make_icons.py         генератор иконок (не нужен для работы)
shortcuts.md          справка: Команда iOS с таймерами (в интерфейсе её нет)
bot/                  отдельный Telegram-бот (лежит только локально)
```

## Версия кэша

```bash
./build.sh     # поднимает VERSION в sw.js
```

Service worker держит файлы в кэше. Если этого не сделать, установленное
приложение останется на старой сборке — поэтому перед публикацией правок
всегда прогоняйте `./build.sh`.

## Публикация на GitHub Pages

Отдаётся **корень репозитория** (ветка `main`, папка `/`). Файл `.nojekyll`
отключает обработку через Jekyll — без него GitHub может не отдать некоторые файлы.

Репозиторий **должен быть публичным** — на бесплатном тарифе приватные
репозитории GitHub Pages не отдают. Секретов в коде нет.

### Один раз

1. Репозиторий: **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main**, folder: **/ (root)**
   - Save

Через минуту адрес: `https://ssgolov.github.io/bread/`

### Обновить после правок

```bash
./build.sh                              # поднимет версию кэша
git add -A && git commit -m "правки" && git push
```

Пуш работает без ввода пароля: на этом Mac в связке ключей лежит
fine-grained токен `bread-push-macbook` (права: Contents — read/write,
только репозиторий `bread`). Он истекает **16 февраля 2027**.

Когда истечёт, `git push` начнёт отвечать `403` / просить пароль. Тогда:

1. github.com → Settings → Developer settings → **Fine-grained tokens** →
   у токена `bread-push-macbook` нажать **Regenerate** (или создать новый:
   only select repositories → `bread`, Contents — Read and write).
2. Сохранить новый токен в связку ключей:

```bash
printf "protocol=https\nhost=github.com\nusername=ssgolov\npassword=ТОКЕН\n\n" \
  | git credential-osxkeychain store
```

Проверить, что записалось: `git credential-osxkeychain get` (спросит
protocol/host/username, выведет пароль).

Удалить токен из связки: `git credential-osxkeychain erase` (те же три поля)
или GitHub → токен → **Delete**.

Pages обновляется за ~1 минуту. Service worker может ещё несколько минут
отдавать старую копию — версия в `sw.js` к этому моменту уже новая,
поэтому приложение подхватит её само при следующем открытии.

### Другие хостинги

Они тоже работают — нужны те же 6 файлов:

- **Cloudflare Pages** — Workers & Pages → Create → Pages → Upload assets.
- **Netlify** — app.netlify.com/drop, перетащить папку.
- **Локальный тест** — `python3 -m http.server 8000` в папке проекта

## Установка на iPhone

PWA ставится **только по HTTPS** и **только из Safari** — с `file://` не заработает.

1. Откройте адрес **в Safari** на iPhone.
2. «Поделиться» (квадрат со стрелкой) → **«На экран Домой»**.
3. Запускайте с иконки — откроется без адресной строки, как приложение.

> Важно: данные Safari-вкладки и установленного приложения — **разные хранилища**.
> Если нажали «Старт» в браузере и потом установили на домашний экран, там будет пусто.
> Планируйте сразу в установленном приложении.

## Что делает кнопка «Старт»

Запускает сессию: сохраняет **абсолютное время старта** (epoch ms) в localStorage.
Дальше прогресс не «тикает», а **пересчитывается** при каждом открытии:

```
текущий шаг = последний, у которого время <= сейчас
прогресс    = (сейчас − начало шага) / (следующий шаг − начало шага)
```

Поэтому закрытие приложения и перезагрузка телефона ничего не ломают —
время шло независимо от приложения.

## Экран выпечки

- Текущий шаг крупно, полоса прогресса этого шага, обратный отсчёт до следующего.
- При смене шага приложение коротко сигналит (нужен первый тап по экрану — этого
  требует iOS, поэтому сигнал звучит только когда приложение открыто).
- **✕ Сброс** — снять сессию, вернуться к настройкам.
- **изменить** — раскрыть настройки, не сбрасывая план.

## Кнопки внизу

- **В календарь (.ics)** — события на каждый этап; напоминание срабатывает
  **в момент события**. Работает без сервера.
- **Скопировать план** — текстом в мессенджер.
- **Печать** — версия для бумаги.

## Предупреждения

- Если какой-то этап попадает в интервал **23:00–06:00**, над планом появляется
  подсказка «Ночью надо спать))» со списком таких этапов и советом сдвинуть
  время начала (или время выпечки). Холодная ночь в холодильнике в этот список
  не входит — она ночью и должна быть.
- Если старт уже прошёл больше трёх часов назад — предложение сдвинуть время.

## Границы, о которых стоит помнить

| | PWA |
|---|---|
| Показать план, прогресс, галочки | ✅ |
| Разбудить при заблокированном экране | ❌ (нужен push с сервера) |
| Поставить будильник | ❌ |

Поэтому утренняя выпечка — **будильник или событие календаря**, а не 18-часовой
таймер: таймеры iOS сбрасываются при перезагрузке, будильники — нет.

## Обновление файлов

После правки `index.html` поднимите версию в `sw.js`:

```bash
./build.sh      # поднимет версию и покажет новую строку
```

Иначе service worker продолжит отдавать старую копию из кэша.
